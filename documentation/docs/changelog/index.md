# Changelog

All notable changes to this project will be documented in this section.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/).

---

## Version Format

```
MAJOR.MINOR.PATCH

MAJOR — incompatible API changes
MINOR — new functionality (backward compatible)
PATCH — bug fixes (backward compatible)
```

## Legend

| Icon | Meaning |
|------|---------|
| :material-plus: | Added — New features |
| :material-sync: | Changed — Changes in existing functionality |
| :material-alert: | Deprecated — Soon-to-be removed features |
| :material-minus: | Removed — Removed features |
| :material-bug: | Fixed — Bug fixes |
| :material-shield: | Security — Security updates |
